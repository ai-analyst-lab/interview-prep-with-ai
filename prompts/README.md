# Prompt pack

Every prompt from the interview prep prompt pack, one file each, for ChatGPT or Claude.ai with nothing installed. Open a file, copy the block, paste it into a new chat, and fill in the brackets. If you use Claude Code, the slash commands (`/kickoff`, `/mock`, `/debrief`, `/retest`) run the same prompts for you.

## The loop
1. **Kickoff once:** 01 or 02 builds your experience database.
2. **Mock daily:** 03 in Practice or Simulate mode, round by round.
3. **Record your practice mocks and debrief them weekly:** 06.
4. **Cold retest every few days:** 07.

Use 04 and 05 before your first recruiter screen, 08 before you submit a take-home, and 09 before each company's loop.

## One tip
Paste your experience database (`me/experience-db.md`) and gaps list (`me/gaps.md`) at the start of every chat. Without them, the coach falls back to generic answers.

Record only practice mocks and your own kickoff talk-through, with the other person's okay. Use AI to prep, not during the interview. Follow each company's rules.
