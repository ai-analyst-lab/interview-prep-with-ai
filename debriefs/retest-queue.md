# Retest queue

Topics to answer again, cold, on a later day. `/debrief` and `/drill` add rows here, and `/retest` asks the ones that are due.

**The rule:** a topic is learned when you answer it correctly, cold, 3 times on 3 different days. Reading the answer doesn't count. Getting it right twice in one day counts once. A miss resets the count to 0/3.

**Tip:** in a chat app, paste this file and `me/gaps.md` at the start of each session so the coach picks up where you left off.
