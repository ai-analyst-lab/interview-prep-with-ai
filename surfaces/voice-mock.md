# Run a spoken practice mock with AI voice mode

Real interviews are spoken. Typed practice hides rambling, filler, and slow starts. A voice mock shows them.

This is for **practice mocks only**: you and an AI (or a friend, peer, or coach who has agreed to it).

1. **Set up the coach.** Open the Claude or ChatGPT Project you set up ([Claude](claude-ai-project.md), [ChatGPT](chatgpt-project.md)), or start a chat and paste the core system prompt and your `me/experience-db.md`.
2. **Tell it the plan in text first.** For example: "Practice mode, case round, role Data Analyst. This will be a spoken mock. Ask one question, let me answer fully, push back once, then give the scorecard."
3. **Open voice mode** in the app and answer out loud. Treat it like the real thing: no notes, no pausing to think for a minute.
4. **Get the transcript.** When you finish, the conversation usually appears as text in the chat. Copy the full exchange. (If your app doesn't show it, record the practice mock with any note taker instead.)
5. **Debrief it.** Save the transcript to `debriefs/inbox/YYYY-MM-DD-<round>.md`, then run `/debrief` in Claude Code, or switch the chat to `Debrief` mode and paste it.

**Tip:** paste `me/gaps.md` and `debriefs/retest-queue.md` at the start of a chat session so it picks up where you left off.

**Doing a practice mock with a friend?** Ask first, then record with any note taker, and save the transcript the same way. See [examples/priya-mock-transcript.md](../examples/priya-mock-transcript.md) for what one looks like.
